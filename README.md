# Water Works

## Play the game

Water Works is a responsive, browser-based charity: water puzzle. Dig a winding path through the earth and guide the flowing water into the signature yellow jerry can.

Open `index.html` in a browser, or start a local server from this folder (for example, with the VS Code Live Server extension).

- Press and drag from the spring to carve a channel through the earth. Guide your tunnel around the solid rock and into the can's spout.
- When the tunnel connects both ends, watch the water flow along it and fill the can.
- Guide 10 drops into the can to win and celebrate with confetti.
- Select **Reset** to try a new path.

The game uses the charity: water logo and colors. Its scene is built with HTML, inline SVG, CSS, and JavaScript; no game library or Canvas API is used.
